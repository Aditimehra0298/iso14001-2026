# Who should attend — card images

Each role card uses a **16:10** photo at the top of the card.

## Required size

| Use | Dimensions | Notes |
|-----|------------|--------|
| Standard | **800 × 500 px** | Minimum for sharp display |
| Retina | **1600 × 1000 px** | Recommended export size |
| Format | JPG or WebP | Keep file size under ~200 KB when possible |

## Filenames (place in this folder)

- `lead-auditors.jpg`
- `internal-auditors.jpg`
- `ems-managers.jpg`
- `consultants.jpg`
- `certification-body-auditors.jpg`
- `organizations.jpg`

Crop subjects center-weighted; avoid important detail at the very top/bottom (card may crop slightly on small screens).
